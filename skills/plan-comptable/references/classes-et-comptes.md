# Plan comptable SYSCOHADA révisé — comptes de référence

Sources : plan comptable SYSCOHADA révisé (plan-comptable-ohada.com, « nouvelle norme 2016 »), consulté le
24/09/2026 ; AUDCIF du 26 janvier 2017. Liste volontairement partielle : les comptes absents ne doivent pas
être inventés (voir SKILL.md, méthode, point 5).
